# 即梦画板原图批量导出

正式版本 v0.5.0，适用于 Windows 上的 Google Chrome 116 及以上版本。扫描有权访问的即梦画板，将上传图和 AI 生成图的原生图片批量保存，按画板保留进度，默认只下载未完成的资源。实测浏览器为 Chrome 155；其他系统和 Chromium 浏览器未完成实测。

从 [GitHub Releases](https://github.com/z15670559513-arch/JimengCanvasExporter/releases) 下载正式 Release ZIP。这是“加载已解压的扩展程序”安装包，未上架 Chrome 应用商店。

## 主要功能

- 读取画板快照中全部图片节点，重复资源去重；缺失关联保留为未解析。
- 上传图走网页正常资源解析；AI 生成图严格核对生成记录和目标图片身份，读取原图地址。
- 多画板任务隔离、增量下载、暂停恢复和失败重试。
- Chrome 默认目录或 Windows 授权文件夹保存，图片尺寸、字节数和 SHA-256 校验。

## 安装

1. 将 Release ZIP 解压到一个长期保留的目录。
2. 打开 `chrome://extensions`，开启“开发者模式”。
3. 点“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
4. 可在 Chrome 工具栏固定插件图标。

ZIP 用于分发，不能直接从扩展管理页安装 ZIP。用户不需要 Node.js、Python，不需要填写 Cookie、Token 或接口参数。

## 扫描与下载

1. 在自己的 Chrome 登录即梦，打开有权限的画板。
2. 点击插件图标打开侧栏。可点“用当前”识别画板，也可粘贴链接；链接指向的画板须在当前窗口打开。
3. 选择 Chrome 默认下载位置，或点“选择指定文件夹”授权自己的导出根目录。
4. 点“扫描图片”。扫描读取画板快照，不需要滚动加载所有 DOM 图片。
5. 核对图片节点、唯一资源、已保存及未完成数量，点“开始下载”。

新画板采用独立子目录；授权目录模式可以在设置里关闭“新画板按 ID 建子目录”。旧版任务始终使用原目录及文件名，不会被新版规则迁移。重复节点引用同一原图默认只保存一份；不同画板的记录独立。

“任务记录与设置”中可先试下载一张或十张生成图。试下载也采用正常原图校验，不使用缩略图，不会创建新的生成任务或扣积分。

## 暂停、恢复与失败

- 点“暂停”停止新请求。正在写入的文件会完成核验；稍后点“继续”。
- 关闭侧栏或浏览器不会删除已完成图片。重开后用当前画板或历史任务恢复，开始前会核对已有文件。
- 同一画板增加图片后重新扫描，只处理新增或未完成资源。
- “重试未完成”重新解析失败和未解析项；没有通过校验的文件不会计为成功。
- 网络错误会按设置重试。连续三次实际下载错误或权限/身份异常会暂停，请查看详细日志。
- 授权目录失效时选择原目录；不要选空的新目录冒充旧目录。插件会保护原完成记录。
- 已解析不等于已保存。全部资源实际完成后显示“全部完成”。

请保持即梦画板及侧栏打开。后台连接短暂丢失时尝试自动恢复；主动暂停或关闭不会自动重新开始下载。当前下载页若导航到另一画板会暂停原任务。

## 保存位置

Chrome 模式只使用浏览器的正常下载流程，文件路径相对于 Chrome 默认下载位置；不能任意写入 Windows 绝对路径。新任务保存到“即梦导出/画板_ID”，旧任务沿用旧子目录。

指定文件夹模式使用用户明确授权的 File System Access API，写入后回读 SHA-256。文件名冲突会另取未使用的名称，不自动覆盖旧图片。任务和句柄只保存在当前用户浏览器本地。

## 设置

支持每批 50/100/200，最大并发 1–3（默认 1），请求间隔 1/2/3 秒，重试 0–2 次。它们是本地调度参数，不代表即梦服务端额度；遇到服务端授权或限流仍停止。

显示已接收字节、实际速度及本轮耗时。数据不足时剩余时间显示未知，不伪造预测。单文件读取上限 128 MiB；保留原生 PNG/JPEG/WebP 字节，不做有损转码。

## 更新与卸载

更新前备份旧解压目录。关闭任务，将新版运行文件放入原已解压目录，在扩展管理页重新加载，再重开侧栏。保留同一路径，避免 Chrome 分配另一个扩展 ID，使历史和授权目录看起来丢失。跨电脑复制 ZIP 不会复制浏览器中的私人任务或授权。

在扩展管理页点“移除”可卸载；它不会删除导出的图片，扩展本地任务和授权数据可能随卸载移除。

## 隐私与验证范围

不要求提供密码、Cookie 或 Token，不上传图片/清单到第三方，不修改即梦画板，不重新生成、不消费积分。不改写 CDN 签名，不以预览冒充原图。详细权限见 PRIVACY.md。

只有已登录并有权限的资源可读取。新版本的实际测试及未验证限制见 RELEASE_TEST_REPORT.md；没有第二个真实账号时不宣称跨账号已验证。

开发者可使用 Source ZIP，按 DEVELOPMENT.md 运行测试和构建；Release ZIP 仅含必要运行文件。

## 常见问题

- 扫描失败：确认当前窗口已打开目标画板、账号已登录且有访问权限。没有权限的画板不能导出。
- 原图未解析或下载失败：保留失败记录，检查登录与网络后点“重试未完成”。插件不改写 CDN 签名，不以其他生成图代替目标图。
- 自定义目录失效：重新授权原目录，再恢复对应历史任务。不要将新空目录当作旧目录。
- 重复节点数量与文件数不同：同一画板中引用同一个原图只保存一份，图片节点与唯一资源数量分别显示。
- 更新后历史消失：先核对是否仍从原路径加载；不同路径可能产生不同扩展 ID。
- 中文显示异常：扩展源码和页面使用 UTF-8。Chrome 菜单、标签页异常尚未证实与扩展有关，不建议据此修改系统区域。

插件仅用于导出用户有权访问的资源，不保证适配即梦未来所有网页版本。跨账号兼容性、长时间在线批量恢复等未验证范围见 [测试报告](RELEASE_TEST_REPORT.md)。
